# Hotwords — example file
#
# Whisper biases its output toward the terms listed here, which dramatically

#

#   1. Copy this file to "hotwords.txt"
#   2. Replace the entries below with your own campaign's terms

#   - Lines starting with "#", "##" or "---" are ignored
